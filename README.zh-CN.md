# Be My Eyes

[English](README.md) | [简体中文](README.zh-CN.md)

**两个人，一个身体。你来操作，朋友当你的眼睛，然后交换。**

Be My Eyes 是一个适用于 Minecraft Java 版的双人合作模组。**操作者**控制共同身体，但看不到世界和共同容器界面；**观察者（眼睛）**看到身体的第一人称视角和支持的容器界面，但不能控制身体。双方按倒计时定时交换职责。

可以直接在普通生存世界中游玩，**不需要专用地图**。

**作者：** aojiangQAQ（鳌江）

## 运行要求

| 项目 | 版本 |
| --- | --- |
| Minecraft Java 版 | 1.21.1 |
| Minecraft Forge | 已验证 52.1.16 |
| Java | 21 |
| Be My Eyes | 0.1.6 |

**双方客户端和专用服务器（如有）都需要安装同一版本。** 局域网联机时，开房者和朋友都要安装。

## 安装

1. 为 Minecraft 1.21.1 安装 Forge。
2. 从 [Releases](https://github.com/aojiangQAQ/Be-My-Eyes/releases) 下载对应版本的模组 JAR。
3. 将 JAR 放入双方客户端的 `mods` 文件夹；使用专用服务器时，服务器也要安装。
4. 升级前移除旧版 JAR，不要同时安装两个版本。

内部模组 ID、配置文件名和存档数据标识仍为 `duosight`，以兼容旧版本。游戏中显示的名称和主指令已更换为 Be My Eyes 和 `/bemyeyes`。

## 开始游玩

双方必须尚未绑定、存活、未乘坐载具、处于生存模式，并在同一维度的 **32 格范围内**。

### 操作书

每位玩家首次进入一个世界时，会领取一本 **Be My Eyes 操作书**。右键书本，或按 **F9** 打开同一个界面，不需要手持书本。快捷键可在 Minecraft 的“控制”设置中修改。操作者和观察者都能使用，操作者界面背后的世界仍保持黑屏。

邀请前选择自己的开局身份和换位间隔，再进入附近玩家页，点击朋友的名字。朋友打开操作书查看邀请并接受，邀请页会显示朋友的开局身份和约定间隔。即使邀请者选择先当观察者，共同身体和背包仍使用邀请者的。

首次成功开局时，会收回双方背包、副手、鼠标携带格和合成格中的实体操作书，普通合成材料会保留。此后使用 **F9** 打开设置；结束玩法、重进或复活都不会返还或重新发书。

开局设置按玩家保存在当前世界中。邀请采用发出时的设置，之后再修改偏好不会改变已经发出的邀请。

玩法中，操作书显示队友、当前身份、剩余时间、间隔选项、立即换位和结束操作。打开时暂停共同输入和换位倒计时；关闭后恢复原来的游戏或容器界面。每次开局都会在聊天区提示当前实际绑定的快捷键，并在倒计时下方短暂显示。

固定档位之外，“**自定义间隔**”页提供 **±1、±10、±60 秒**调整，自动限制在 15–3600 秒。调整后保留当前书页；双方同时操作时，以最新的共同间隔累加，不会互相覆盖。

设置操作有 **300 毫秒客户端冷却**及每位玩家 **5 个服务器刻的限频**。打开和自动刷新请求也会限频，重复刷新会合并。书页点击使用模组专用消息，不再发送原版聊天指令。

首次玩法开始前，丢失的书可以用 `/bemyeyes book give` 补领。背包满时不会挤掉原有物品，快捷键和 `/bemyeyes book` 始终可以使用。

### 指令

想要把自己的身体作为共同身体的玩家发出邀请：

```text
/bemyeyes invite 朋友的游戏名
```

另一位玩家接受：

```text
/bemyeyes accept
```

发起者的身体、背包和经验成为共同身体。朋友原来的物品不会合并到共同背包；结束后恢复朋友的位置、背包、经验和正常操作。

共同身体死亡或任意一位玩家离线时，绑定结束。

## 指令与操作

| 指令或按键 | 作用 |
| --- | --- |
| `/bemyeyes invite <玩家>` | 邀请附近的玩家共用自己的身体。 |
| `/bemyeyes accept` | 接受有效邀请。 |
| `/bemyeyes decline` | 拒绝邀请。 |
| `/bemyeyes book` | 不依赖书本物品，直接打开操作书。 |
| `/bemyeyes book give` | 尚未开始过玩法时补领操作书。 |
| `/bemyeyes role driver` 或 `/bemyeyes role eyes` | 为下一次自己发出的邀请选择先操作或先观察。 |
| `/bemyeyes interval <秒数>` | 范围为 15–3600 秒；已绑定时修改当前间隔并重启倒计时，未绑定时保存为下一次邀请的开局间隔。 |
| `/bemyeyes interval add <秒数>` | 在最新间隔上加减秒数，自动限制在 15–3600 秒。 |
| `/bemyeyes swap` | 立即交换职责并重启倒计时，维度加载期间不可使用。 |
| `/bemyeyes status` | 查看当前间隔和剩余时间。 |
| `/bemyeyes stop` | 结束绑定。 |
| `F8` | 立即结束绑定。 |
| `F9`（可改绑） | 打开或关闭自己的操作书。 |
| `T` 或 `/` | 打开原版聊天框或指令输入，支持修改聊天键位。 |
| `ESC` | 操作容器时关闭共同容器，或打开自己的暂停菜单。 |

默认每 **120 秒**换位，双方屏幕上方均显示倒计时。旧指令 `/duosight` 保留为 `/bemyeyes` 的兼容别名。

### 聊天与菜单

操作者和观察者都能使用原版聊天、消息历史和指令补全。消息与指令以输入者自己的身份发送，遵循该玩家正常的服务器权限。

暂停菜单、设置、操作书和聊天框不会解除绑定。打开期间暂停共同身体的输入和换位倒计时；关闭后继续，并恢复共同容器界面。

操作者可以看到自己的菜单和聊天，但世界画面仍保持黑屏。观察者聊天时保留身体的第一人称视角。

铁砧改名框或配方书搜索框聚焦时，操作者的文字输入优先进入该文本框，不会误打开聊天。共同背包和容器仍由操作者操作。

## 配置

首次打开世界后，可编辑该世界的 `serverconfig/duosight-server.toml`：

```toml
swapSeconds = 120
inviteSeconds = 60
```

| 配置项 | 作用 | 范围 |
| --- | --- | --- |
| `swapSeconds` | 默认换位间隔，单位为秒。 | 15–3600 |
| `inviteSeconds` | 邀请有效期，单位为秒。 | 10–300 |

编辑后重启世界或服务器。`/bemyeyes interval` 不修改服务器默认值：已绑定时修改当前间隔，未绑定时修改输入者的下一次邀请偏好。

## 语言

模组提示跟随每位玩家自己的 Minecraft 语言设置：

- 简体中文、繁体中文（台湾）、繁体中文（香港）：统一显示 **简体中文**。
- 其他语言：显示 **英文**。

不需要设置服务器语言。

## 支持的界面与限制

已验证背包，以及以下 20 种原版容器在两种身份下的操作：

附魔台、铁砧、砂轮、锻造台、切石机、织布机、制图台、信标、熔炉、高炉、烟熏炉、酿造台、箱子、木桶、潜影盒、漏斗、发射器、投掷器、合成器和工作台。

- **告示牌编辑、书本编辑等非容器界面尚未同步。**
- 共享配方书需让双方保持相同的宽窄布局，不同布局可能导致点击错位。个人操作书不受此限制。
- 非原版界面、光影和改变摄像机或输入的模组未作兼容保证。
- 绑定期间锁定第一人称并屏蔽调试视图。
- 网络延迟仍会影响操作和视角同步。
- 建议先备份世界再试用。

## 验证

0.1.6 已通过 **45 项单元测试**和两个 Forge 客户端的联机回归，覆盖：

- 首次进服发书、点击设置、开局身份、邀请设置快照、两种身份打开操作书、容器恢复、F9 改绑 F10，以及跟随实际键位的开局提示。
- 背包、副手、鼠标携带格和合成输入格的收书，普通材料保留，以及开始过玩法、末地返回后不再通过登录或补领发书。
- 双方自定义加减的累加、15–3600 秒边界和书页保留；约一万次快速点击和 400 条操作、刷新消息的集中发送，书页压测阶段使用无管理员权限的朋友客户端。
- 上述 20 种容器，两种身份下的操作与界面内换位。
- 双方同时聊天、普通消息和指令、历史记录、指令补全、改绑聊天键、容器恢复及操作者聊天时的黑屏。
- 8 种宽窄配方书布局、24 个光标位置、地图预览、铁砧改名和持有物品时的换位。
- 主世界、下界、末地和末地返回，两种身份下的维度切换；个人菜单和结束绑定后的背包、经验及正常操作恢复。
- 简体中文、台湾繁体、香港繁体，以及英文、日语、法语、德语设置下的模组提示。

个人操作书已检查 640x480 和 1024x768 布局。共享配方书测试使用双方一致的窄布局或宽布局。

## 从源码构建

安装 **JDK 21**，使用项目自带的 Gradle Wrapper。

Windows：

```powershell
.\gradlew.bat build
```

Linux 或 macOS：

```bash
./gradlew build
```

发布 JAR 位于 `build/libs`。运行 `gradlew test` 可执行单元测试。

`src/smoke` 为开发验证代码，不会包含在发布 JAR 中。运行目录、测试存档、日志和本机构建文件不会上传到仓库。
