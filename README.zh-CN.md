# Be My Eyes

[English](README.md) | [简体中文](README.zh-CN.md)

**两个人，一个身体。你来操作，朋友当你的眼睛，然后交换。**

Be My Eyes 是一个适用于 Minecraft Java 版的双人合作模组。**操作者**控制共同身体，但看不到世界和共同容器界面；**观察者（眼睛）**看到身体的第一人称视角和支持的容器界面，但不能控制身体。双方按倒计时定时交换职责。

可以直接在普通生存世界中游玩，**不需要专用地图**。

**作者：** aojiangQAQ（鳌江）

## 运行要求

| 项目 | 版本 |
| --- | --- |
| Minecraft Java 版 | 1.21.1 |
| Minecraft Forge | 已验证 52.1.16 |
| Java | 21 |
| Be My Eyes | 0.1.4 |

**双方客户端和专用服务器（如有）都需要安装同一版本。** 局域网联机时，开房者和朋友都要安装。

## 安装

1. 为 Minecraft 1.21.1 安装 Forge。
2. 从 [Releases](https://github.com/aojiangQAQ/Be-My-Eyes/releases) 下载 `be-my-eyes-1.21.1-0.1.4.jar`。
3. 将 JAR 放入双方客户端的 `mods` 文件夹；使用专用服务器时，服务器也要安装。
4. 升级前移除旧版 JAR，不要同时安装两个版本。

内部模组 ID、配置文件名和存档数据标识仍为 `duosight`，以兼容旧版本。游戏中显示的名称和主指令已更换为 Be My Eyes 和 `/bemyeyes`。

## 开始游玩

双方必须尚未绑定、存活、未乘坐载具、处于生存模式，并在同一维度的 **32 格范围内**。

想要把自己的身体作为共同身体的玩家发出邀请：

```text
/bemyeyes invite 朋友的游戏名
```

另一位玩家接受：

```text
/bemyeyes accept
```

发起者的身体、背包和经验成为共同身体。朋友原来的物品不会合并到共同背包；结束后恢复朋友的位置、背包、经验和正常操作。

共同身体死亡或任意一位玩家离线时，绑定结束。

## 指令与操作

| 指令或按键 | 作用 |
| --- | --- |
| `/bemyeyes invite <玩家>` | 邀请附近的玩家共用自己的身体。 |
| `/bemyeyes accept` | 接受有效邀请。 |
| `/bemyeyes interval <秒数>` | 设置当前绑定的换位间隔，范围为 15–3600 秒，并重启倒计时。 |
| `/bemyeyes swap` | 立即交换职责并重启倒计时，维度加载期间不可使用。 |
| `/bemyeyes status` | 查看当前间隔和剩余时间。 |
| `/bemyeyes stop` | 结束绑定。 |
| `F8` | 立即结束绑定。 |
| `T` 或 `/` | 打开原版聊天框或指令输入，支持修改聊天键位。 |
| `ESC` | 操作容器时关闭共同容器，或打开自己的暂停菜单。 |

默认每 **120 秒**换位，双方屏幕上方均显示倒计时。旧指令 `/duosight` 保留为 `/bemyeyes` 的兼容别名。

### 聊天与菜单

操作者和观察者都能使用原版聊天、消息历史和指令补全。消息与指令以输入者自己的身份发送，遵循该玩家正常的服务器权限。

暂停菜单、设置和聊天框不会解除绑定。打开期间暂停共同身体的输入和换位倒计时；关闭后继续，并恢复共同容器界面。

操作者可以看到自己的菜单和聊天，但世界画面仍保持黑屏。观察者聊天时保留身体的第一人称视角。

铁砧改名框或配方书搜索框聚焦时，操作者的文字输入优先进入该文本框，不会误打开聊天。共同背包和容器仍由操作者操作。

## 配置

首次打开世界后，可编辑该世界的 `serverconfig/duosight-server.toml`：

```toml
swapSeconds = 120
inviteSeconds = 60
```

| 配置项 | 作用 | 范围 |
| --- | --- | --- |
| `swapSeconds` | 默认换位间隔，单位为秒。 | 15–3600 |
| `inviteSeconds` | 邀请有效期，单位为秒。 | 10–300 |

编辑后重启世界或服务器。`/bemyeyes interval` 仅改变当前绑定的间隔。

## 语言

模组提示跟随每位玩家自己的 Minecraft 语言设置：

- 简体中文、繁体中文（台湾）、繁体中文（香港）：统一显示 **简体中文**。
- 其他语言：显示 **英文**。

不需要设置服务器语言。

## 支持的界面与限制

已验证背包，以及以下 20 种原版容器在两种身份下的操作：

附魔台、铁砧、砂轮、锻造台、切石机、织布机、制图台、信标、熔炉、高炉、烟熏炉、酿造台、箱子、木桶、潜影盒、漏斗、发射器、投掷器、合成器和工作台。

- **告示牌编辑、书本编辑等非容器界面尚未同步。**
- 非原版界面、光影和改变摄像机或输入的模组未作兼容保证。
- 绑定期间锁定第一人称并屏蔽调试视图。
- 网络延迟仍会影响操作和视角同步。
- 建议先备份世界再试用。

## 验证

0.1.4 已通过 **25 项单元测试**和两个 Forge 客户端的联机回归，覆盖：

- 上述 20 种容器，两种身份下的操作与界面内换位。
- 双方同时聊天、普通消息和指令、历史记录、指令补全、改绑聊天键、容器恢复及操作者聊天时的黑屏。
- 8 种宽窄配方书布局、24 个光标位置、地图预览、铁砧改名和持有物品时的换位。
- 主世界、下界、末地和末地返回，两种身份下的维度切换；个人菜单和结束绑定后的背包、经验及正常操作恢复。
- 简体中文、台湾繁体、香港繁体，以及英文、日语、法语、德语设置下的模组提示。

## 从源码构建

安装 **JDK 21**，使用项目自带的 Gradle Wrapper。

Windows：

```powershell
.\gradlew.bat build
```

Linux 或 macOS：

```bash
./gradlew build
```

发布 JAR 位于 `build/libs`。运行 `gradlew test` 可执行单元测试。

`src/smoke` 为开发验证代码，不会包含在发布 JAR 中。运行目录、测试存档、日志和本机构建文件不会上传到仓库。
